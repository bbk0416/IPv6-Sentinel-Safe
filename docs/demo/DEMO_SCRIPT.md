# Portfolio Demo Script

## 30초 설명

IPv6 Sentinel Safe는 실제 네트워크를 건드리지 않고 IPv6 보안 이벤트를 시뮬레이션하는 교육용 대시보드입니다. DHCPv6, DNS, Neighbor Discovery, Router Advertisement 같은 관측 이벤트를 안전하게 생성하고, 이를 실시간 로그·자산 목록·안전 점수·성능 지표로 보여줍니다.

## 2분 시연 흐름

1. `python app.py` 또는 `docker compose up --build`로 실행합니다.
2. 브라우저에서 `http://127.0.0.1:5000`을 엽니다.
3. **데모 시나리오** 버튼을 눌러 발표용 샘플 데이터를 즉시 생성합니다.
4. 자산 목록에서 `lab-router`를 클릭해 상세 모달을 보여줍니다.
5. 실시간 관측 로그와 안전 점수 변화를 설명합니다.
6. **스냅샷 JSON 저장** 또는 **로그 CSV 저장**으로 결과 내보내기를 보여줍니다.
7. `/api/ready`와 `/api/info`로 안전 모드가 켜져 있음을 확인합니다.

## 강조할 포인트

- 실제 패킷 캡처/전송/스캔 기능을 제거한 안전 설계
- 로컬 기본 바인딩과 원격 바인딩 안전장치
- Flask + Socket.IO 기반 실시간 대시보드
- Docker, CI, 테스트, 배포 문서까지 포함한 포트폴리오형 구성


## CDN 접근 제한 환경 안내

시연 장소에서 CDN 접속이 제한되면 대시보드가 자동으로 **REST fallback** 모드로 바뀝니다. 이 경우 실시간 소켓 이벤트 대신 로컬 API 폴링으로 통계·자산·로그를 갱신하며, 데모 시나리오와 샘플 자산 생성 버튼도 계속 작동합니다.
