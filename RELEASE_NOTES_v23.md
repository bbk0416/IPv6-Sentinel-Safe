# Release Notes v23.0.0-safe

## Focus

v23 improves validation hygiene for the safe IPv6 security-event simulator. It does not add live IPv6 packet capture, packet sending, network scanning, DHCPv6/DNS manipulation, or intrusion-detection capability.

## Changes

- Added `services/validation_hygiene.py` to check whether the validation flow cleans generated cache artifacts and documents the canonical clean validation path.
- Added `scripts/check_validation_hygiene.py` for dependency-light validation hygiene review.
- Added `docs/quality/VALIDATION_HYGIENE.md` to explain the validation-cleanliness boundary and limitations.
- Updated `scripts/validate_project.py` to clean generated bytecode/cache artifacts before and after validation so local validation does not leave a dirty release workspace.
- Updated the quality gate, release audit, manifest, CI, and Makefile references to include validation hygiene.

## Honest limitation

The project remains a portfolio/education simulator. Passing v23 validation means the release package is cleaner and more internally consistent; it does not prove real network monitoring or security detection.
