# Release Notes v5.0.0-safe

v5 adds demo-handoff improvements for the local safe simulator.

## Added

- One-click portfolio demo scenario endpoint: `POST /api/demo/scenario`
- Dashboard button for deterministic demo data generation
- API reference document
- OpenAPI 3.0 YAML contract
- Portfolio demo script
- Quick-start checklist
- Project manifest for release review
- Additional packaging and API documentation tests

## Improved

- README now documents the demo scenario flow and v5 validation target
- Project version updated to `6.0.0-safe`
- Static validation now checks v5 release artifacts

## Safety statement

This release remains simulation-only. It does not capture packets, transmit packets, scan real networks, or modify network behavior.
